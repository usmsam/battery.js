# battery.js

## Суть
Учебный мини-проект по Battery Status API браузера: показывает уровень заряда и статус зарядки устройства в реальном времени, реагируя на события батареи. Демонстрация работы с нативным Web API.

## Стек
- **Vanilla JS** + HTML + CSS (без зависимостей и сборки).

## Архитектура
- `inni/index.html` — разметка индикатора батареи.
- `inni/index.js` — логика: `navigator.getBattery()` + подписка на события.
- `inni/style.css` — оформление.

## Фичи
- **Уровень заряда:** отображение текущего процента.
- **Статус зарядки:** «CHARGING NOW» и реакция на `chargingchange`.
- **Реалтайм-обновление:** обновление UI по событиям Battery API.

## Сложные места
- **Battery Status API.** Промис `navigator.getBattery()` и подписка на события (`chargingchange`, `levelchange`) — работа с асинхронным нативным API без библиотек.

## Кейсы
- **«Нативный Battery API вживую».** Чтение заряда и статуса без зависимостей, обновление по событиям.
- **Статус: до ИИ.**
- *Примечание: учебный проект; Battery API поддерживается не во всех браузерах.*
